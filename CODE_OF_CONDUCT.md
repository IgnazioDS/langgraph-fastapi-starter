# Code of Conduct

## Our standard

We want this project to be a useful, welcoming place for people building reliable AI
systems. Participate with curiosity, technical honesty, and respect.

Expected behavior includes:

- giving actionable, good-faith feedback;
- disagreeing with ideas without attacking people;
- respecting different backgrounds, experience levels, and communication styles;
- protecting private information and reporting security concerns responsibly;
- acknowledging mistakes and helping move discussions toward resolution.

Harassment, discrimination, threats, personal attacks, sexualized attention, deliberate
intimidation, and sustained disruption are not acceptable.

## Scope

This standard applies in issues, pull requests, discussions, code review, and other
spaces where someone is representing the project.

## Reporting and enforcement

Report unacceptable behavior privately to `ignaziodesantisofficial@gmail.com`. Include
relevant links or context when possible.

Reports will be reviewed promptly and handled as confidentially as practical. Project
maintainers may edit or remove contributions, lock conversations, issue warnings, or
temporarily or permanently restrict participation when behavior violates this standard.

Retaliation against someone who raises a good-faith concern is itself a violation.
